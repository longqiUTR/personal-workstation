# 关键决策与被否决的方案

记录**为什么这么做**，以及**为什么不那么做**。被否决的方案同样重要——防止半年后有人重新提一遍，再论证一遍。

## 核心决策

### 为什么是"学习发生在工作台里"而不是"追踪面板"

追踪面板（倒计时 + 打卡 + 成绩曲线，学习在别处进行）看起来轻得多，但有两个致命问题：

1. **需要手工喂数据**，违反零录入约束
2. **完全依赖自律**，正好踩中使用者自述的第三个痛点"坚持不下去"

把学习行为放进工作台，数据就成了训练的副产品——这是"零录入"唯一能真正成立的方式。听写这个动作本身就产出了：听了几遍、对了几个词、错了哪些词、花了多久。

### 为什么不内置 4500 词表背单词

见 [user-profile.md](user-profile.md)。使用者词汇量已覆盖四级，这是无效劳动。

**替代方案**：只背自己真的听错的词——听写错词自动入 FSRS 队列。这个词库是使用者真实缺口的精确映射，比任何通用词表都准。

### 为什么用 FSRS 而不是 SM-2

- FSRS 基于 7 亿+ 条真实复习记录训练，相同记忆保持率下**减少 20-30% 复习量**
- SM-2 有"低间隔地狱"：ease factor 易降难升，连按几次 Again 后间隔几乎不增长，卡片反复出现
- FSRS 支持设定目标记忆保持率，SM-2 无此机制

**已知限制**：约 1000 次复习以下，FSRS 无法拟合个人模型，回退默认参数，表现与 SM-2 接近。本项目前期数据量小，这可接受——不要因为"早期看不出差别"就换回 SM-2，后期差距会显现。

### 为什么保命档必须存在

使用者反馈"全句听写太累"。如果最低门槛是"打完一整句"，疲劳期就会直接断线，而断线正是痛点之首。

保命档（听一句 → 点懂/没懂 → 看原文，3 分钟一轮）的设计意图是：**让断线的成本低到不可能断**。

**它同样点亮热力图。** 有人可能觉得"保命档太水不该算打卡"——恰恰相反，让它算数才是它存在的意义。

### 为什么趋势主指标是模考分数而不是听写正确率

听写正确率会随档位切换跳变，且轻档的分母（挖空词数）是系统自选的，纵向可比但横向不可比。用它当"我变强了"的证据会误导。

模考听力分数才是跨档可比的硬证据。听写正确率降为辅指标，且**按档位分线绘制**。

## 被否决的方案

| 方案 | 否决理由 |
|---|---|
| 内置 4500 词表系统化背词 | 使用者词汇量已覆盖四级，无效劳动 |
| 纯追踪面板 | 不解决听力短板，依赖自律，踩中"坚持不下去"痛点 |
| 全科应试台（听说读写译） | 70% 工程量花在使用者不缺的能力上 |
| **WhisperX 强制对齐做切句** | 本机无 ffmpeg；需 torch + wav2vec2 数 GB 依赖；CPU 上对齐是瓶颈。**而听写只需 ±0.3 秒精度，根本不需要词级对齐**——这个认识砍掉了整条重依赖链 |
| 跟读 / 影子跟读替代听写 | 自动判分难度大得多，需重新设计评分机制。可作为后续扩展，但不是第一期 |
| 复习时让用户手点 Again/Hard/Good/Easy | 违反零录入，且用户自评不可靠。改为复用听写形式自动判分，见 [srs.md](srs.md) |
| 五条线一起做 | 使用者主动收敛为"暂时只考虑四级"。先做透一条 |

## 实施里程碑（切两刀）

距考试只剩三个月，**能早一天开始训练比功能完整重要得多**。

| 里程碑 | 内容 | 完成后 |
|---|---|---|
| **M1** | 本地导入（LRC/SRT）+ 四档听写循环 + diff 判定 + 错词入库 + FSRS 调度 + 独立复习 | **已经可以每天训练了** |
| **M2** | 总览页 + 模考记录 + 静音检测自动切句 + RSS 自动抓取 | 反馈与自动化供料就位 |

M1 是完整闭环不是半成品：素材进得来、能听写、错词能复习。M2 全是"让这件事更舒服"的东西——重要，但不能挡在开始训练前面。

总览页放进 M2 是刻意的：它解决的"怕掉线、没反馈"**要先有数据才有意义**。M1 跑两周后再做，那时才知道哪些指标真正有用。

⚠️ **`daily` 表的归属必须在计划里写明**：档位自动调节要读"该档位有记录的日子的正确率"，数据源是 `daily.accuracy_by_mode_json`。但 `daily` 看起来像总览页（M2）的东西——**M1 若不做 `daily` 汇总，档位自动调节就跑不起来**。二选一：把 `daily` 划进 M1，或写明 M1 阶段从 `attempts` 现算。

## 实施优先级（不要搞反）

1. **本地文件导入 + LRC/SRT 切句 + 核心听写循环** —— 没有这个整个系统没有意义
2. 错词库 + FSRS 复习
3. 总览页
4. 静音检测自动切句（独立子系统，见 [materials.md](materials.md)）
5. RSS 自动抓取

RSS 抓取虽然最符合"零录入"理念，但**优先级最低**：手动下个 mp3 + 复制一段 transcript 只要两分钟，而核心循环不通，系统就是零。

先让训练能跑起来，再谈自动化供料。
